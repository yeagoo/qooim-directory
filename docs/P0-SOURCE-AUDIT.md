# P0 来源核查与隔离结论

日期：2026-10-18。结论仅针对本轮技术验证，不构成对旧仓库整体权属或未来公开发行的判断。

| 来源范围 | 证据与处理 | 当前状态 |
| --- | --- | --- |
| `p0/`、`app/`、`scripts/` 和本工作区配置 | 本工作区新编写的验证实现；未复制旧源码或旧 Git 历史 | 纳入 P0 |
| 设计文档 | 根据用户方向及调研新编写；内部背景单独忽略 | 公开候选与内部材料分离 |
| 旧站点注册、Host、可见性、网络安全候选代码 | 内部清单记录文件和来源修订；权属/通知未核实 | 全部排除，未迁入 |
| 旧站品牌、内容数据库、图片、商业素材 | 未作为演示数据或运行依赖引入 | 全部排除 |
| 直接依赖 | 锁文件固定版本；检查包内实际 LICENSE/NOTICE 并记录 SHA-256 | 清单见 [依赖记录](DEPENDENCIES.md) |
| PostgreSQL 测试镜像、浏览器、系统工具 | 通过本机工具安装/执行，不复制进项目源码 | 将来分发镜像需另做分发清单 |
| 内部证据、临时密钥和测试域 | `.local/`、环境文件、构建和测试输出被忽略；临时凭据随隔离运行器清理 | 不进入公开材料 |

内部来源修订和依赖许可文件摘要保存在 `.local/`；不把内网路径、完整失败日志或一次性授权参数加入公开文档。直接依赖声明及随包文本的核查，不等同于完整传递依赖分发审计。

## 许可证与发布门槛

本轮没有迁入旧代码、公开发布或赋予新项目最终开源许可证。`package.json` 保持 private，避免把技术验证完成误认为公开授权已完成。

原 P0 退出规则要求“来源清单完成、未解决项隔离、批量迁入前确定许可证”。本轮来源已分类，未决旧代码全部排除，因此不以尚未发生的批量迁入或公开发布阻塞新写原型验证。最终许可证仍须在首次批量迁入或公开发行前由维护者确定；不能沿用旧仓库根许可证替代该决策。

首次公开提交仍须检查暂存区，首次推送检查完整待推历史。当前没有新建公开仓库或提交发布历史，忽略规则不能被当作历史清理的证据。

## P5 决策更新

维护者在 P5 明确选择 AGPL-3.0，项目声明为 AGPL-3.0-only，完整 LICENSE 已加入。上文的“待确定”是 P0 历史状态，不再是当前许可证状态。仍未迁入旧平台源码；镜像的完整系统/原生依赖分发审计和真实外部 OAuth 联调不因许可证选择而自动完成。
