# 后台列表请求顺序 Review

日期：2026-10-18。本轮沿用现有后台内容接口，处理同一路由内整页载入与跨路由加载状态的交错。

## 复现与修复

旧实现的后台路由代次只区分页面切换，编辑器保护只区分当前记录和手工编辑。资源翻页等待期间仍可以搜索；搜索先返回后，迟到的旧翻页会整页重建，清空查询并替换搜索结果。新增真实浏览器测试在原代码上失败：查询输入从 `selection-first` 变成空字符串，原有23项内容回归仍通过。

资源列表与本站内容整页载入现在共用工作区级请求标记。开始新载入会使前一次失效；回填与异常传播都要核对当前标记，并继续遵守已有编辑器保护。过期错误不覆盖提示，旧请求的完成也不能清除较新载入的 `aria-busy`。标记由WeakMap持有，后台路由切换主动失效旧标记，加载状态由新路由接管。

同页载入保留可用的搜索输入；当前搜索失败保留原列表和输入、恢复按钮，允许重试。初次进入或切换后台路由仍沿用原有inert保护。请求经过原有会话、权限和Host检查，服务端仍是授权依据；没有把界面失效保护当成撤销请求或事务回滚。

这不改变发布记录局部刷新的既有代次与版本接续机制，也不改变保存操作的服务端语义。整页搜索、翻页成功后仍会重建该内容页；没有增加未保存编辑提醒或承诺跨分页保留草稿。

## 验证范围

浏览器通过真实HTTPS接口人为扣留旧响应，覆盖旧资源翻页晚于新搜索、旧请求503晚于新搜索开始、当前搜索503后的按钮恢复与重试，以及本站内容翻页后切换到仍在加载的资源页。最后一个场景同时核对新路由的aria-busy和inert归属。

首轮修复后P1 15项、P2 25项、P4 17项共57项正常退出0；补充内容翻页跨路由用例后，P2最终26项正常退出0。发行10项回归也正常退出0，共68项不同回归，不累计重复执行。生产build和随后顺序执行的check均正常退出0。严格release:check仍因原有四项许可缺口退出1，没有放宽发行门槛。

本轮未重复Docker整体验收、容量测试或真实OAuth联调，也不将此前结果计入本轮。日志：`.local/list-order-{baseline,tests,content-final,release,build,check,gate,bundle,export}.log`。源码候选：`.local/list-order-review-20261018`；最终记录保存后重新生成归档、导出并核对全部文件摘要。

没有新增接口、依赖、静态资产或数据库迁移；旧站与生产环境未改动，没有公开发布。正式品牌、真实OAuth联调、四项许可缺口与镜像分发核查仍见 [发行边界](RELEASE-REVIEW.md)。操作协议见 [内容管理](P2-CONTENT.md)。
