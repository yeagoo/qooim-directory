# P0 关键设计验证计划

状态：P0 原定范围已完成。逐项执行证据、Review 修复和退出结论见 [最终验收](P0-FINAL.md)。下列场景与退出规则保留，未因收尾而删减。

产品规则见 [配置协议](CONFIGURATION.md)、[账号设计](IDENTITY.md)、[公共数据访问](DATA-ACCESS.md)。目标是验证影响底座最大的设计，输出可复现证据后再开展完整产品实现。

## 执行与证据

只使用隔离数据库、演示数据、本地测试域，不连接既有生产数据库、邮件或 OAuth 应用。模拟提供方的结果不等于真实第三方集成通过。

每个场景记录依赖版本、命令、输入、预期、实际结果、日志或测试路径及通过/失败/阻塞状态。内部材料放入被忽略的 .local/，公开报告脱敏。

原型可以使用临时界面，但真实多域会话和数据库并发不能用 mocks 代替。并发使用可控屏障，不仅重复尝试碰运气。

## 配置场景

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| C01 | 后台与文件基于同版本改同字段 | 后到操作冲突，线上未覆盖 |
| C02 | 两人编辑共享草稿 | 草稿版本拦截迟到保存 |
| C03 | 导航重排与删除冲突 | 整列表比较，展示删除，不逐索引自动拼接 |
| C04 | 重复导入同快照 | 无重复发布，版本检查不跳过 |
| C05 | 他站文件、未知字段和旧 Schema | 拒绝或显式已测试转换，不静默丢字段 |
| C06 | 必填缺失、可选缺失、null、数组缺项 | 符合 Schema，不删除业务数据 |
| C07 | 导入时已有他人草稿 | 展示差异，显式替换并校验草稿版本 |
| C08 | 发布期间草稿或线上版本变化 | 比较并交换失败，不发布混合快照 |
| C09 | 提交前中断 | 旧线上快照完整，无半发布 |
| C10 | 提交后刷新失败或响应丢失 | 可查真实状态，重试不重复发布 |
| C11 | 回滚依赖不存在或不兼容 | 拒绝；修复后作为更高修订发布 |

## 账号场景

至少三个不同主域的本地 HTTPS 演示站，通过重置空测试库覆盖独立、共享和混合模式。至少 Chromium、Firefox；WebKit 能运行时纳入，否则列为公开版本前必须完成项。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 独立空间同邮箱注册 | 不同用户与会话，不能跨空间登录 |
| A02 | A 发起、B 中心、C 再登录 | 稳定身份映射，C 免重复输入，各域 Cookie 正确 |
| A03 | 共享与独立混合 | 共享会话不能进入独立空间 |
| A04 | 按 Host 访问认证路由 | 空间、Cookie、issuer、来源、回调正确 |
| A05 | 错误 state/nonce、重放代码、错误回调 | 适用校验拒绝且不建会话 |
| A06 | 中心不可达，有效或过期本地会话 | 有效会话按规则继续，过期和新登录失败，不降级 |
| A07 | 数据库失效、封禁和撤销权限 | 受保护操作失败，不因缓存继续授权 |
| A08 | 本站退出和全空间退出 | 不自动重登，全局撤销后续请求生效 |
| A09 | 邮件注册与找回密码 | 链接和身份属于正确空间 |
| A10 | 并发注册与外部身份关联冲突 | 唯一约束生效，不错误合并 |
| A11 | 有用户后改空间或删除中心 | 首版拒绝，明确受影响对象 |
| A12 | 迁移模型演练 | 邮箱碰撞、重复收藏和权限冲突有映射，不隐式合并或扩大权限 |

A12 只证明模型和迁移设计，不表示交付迁移工具。真实外部 OAuth 联调与安全评审在产品化阶段继续完成。

## 运行时与数据边界

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| R01 | 不重启新增站、改语言及别名 | 使用已发布版本；框架静态路由限制有验证过的方案 |
| R02 | 两进程持旧配置后发布 | 在检查窗口内收敛，记录传播耗时 |
| R03 | TTL 到期数据库不可用 | 503，不无限沿用旧配置或串站 |
| R04 | 停站、停模块、紧急下架 | 下一请求权威门控拒绝，不受旧配置影响 |
| R05 | 伪造 Host/转发头、未知域名 | 无品牌 404，不进入错误认证空间或后台 |
| R06 | 模板直接和间接导入数据库、读环境变量 | 边界检查失败 |
| R07 | 跨站 slug、搜索、计数、推荐、API、sitemap | 排除不可见内容，仅公开字段 |
| R08 | 草稿预览、缺失译文 | 预览鉴权且不进公共缓存，缺失译文不进 SEO 列表 |

P0 至少以列表、详情、预览和一条公开 API 原型验证 R07/R08；其余真实页面覆盖落实 P2/P3，不以原型代替完整产品回归。

## 来源与许可核查

迁入前为候选代码逐项记录来源仓库和修订、文件范围、许可证及通知、素材来源、依赖、权属疑问、复用/改写/排除决定及证据。

包元数据不能代替来源核查；改名不能消除来源义务。未确认候选先排除，不阻止其他来源明确代码使用。最终许可证在批量迁入前确定；本轮来源与隔离结论见 [来源核查](P0-SOURCE-AUDIT.md)，最终许可证仍是批量迁入/公开发行前的门槛。

内部清单放 .local/，公开归属清单使用适合发布的材料。首次提交检查忽略规则和暂存区，公开推送检查全部历史。

## 退出标准

- C01–C11 有真实执行结果与失败恢复证据。
- A01–A11 通过，或完成经审阅的替代设计并重测；A12 有模型演练结论。
- R01–R06 通过；R07/R08 最小入口验证可行，后续全页面测试有阶段归属。
- 来源清单完成，未解决项隔离，批量迁入前确定许可证。
- 依赖版本锁定，明确认证和动态配置限制，更新工作量估算。

未执行保持待执行，不能把未通过的核心项改称后续优化就宣布完成。P0 结束输出验证报告、设计修订与重新估算，再进入 P1。
