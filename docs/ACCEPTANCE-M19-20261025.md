# M19 验收记录：后台方案 3（黑白高对比）

日期：2026-10-25。分支 `m19-admin-v3`，已合并进 `main`（c54f9f9）。设计稿在私有画布上，QooIM 从六个方案中选定方案 3。这是本地回归记录，不是发布批准。

## 内容

- **布局**：
  - 去掉侧栏，改为固定在顶部的栏和 7 个标签。
  - 顶栏包括 logo、"/ Qoo.IM 站群"、⌘K 搜索框、"统一分发"按钮和账号菜单。
  - 原有元素的 id 保持不变。
- **主题**：
  - 黑白配色，浅色和深色各一套。
  - 账号菜单里可以选"跟随系统 / 浅色 / 深色"，选择存在浏览器里，读取失败时按跟随系统处理。
  - 新样式只作用于后台和后台登录页（`body.console`），前台不受影响。
- **字体**：使用镜像里已有的 Geist（OFL），由后台域名自己提供，没有新增依赖；表格数字使用等宽字体。
- **总览页**：
  - 每个站点一张卡片，显示已发布、草稿、待审投稿的数量和状态。
  - 新增 `GET /content/site-stats`，只返回操作员能看到的站点。
  - 右侧"最近活动"来自审计日志；不是全局管理员的操作员，合并显示自己最多 5 个站点的活动。
- **⌘K / Ctrl+K 命令面板**：可以跳转页面和站点，全局管理员还能搜索资源。支持中文输入法组字，带可访问性标注。
- **状态**：统一的状态颜色；加载时显示骨架屏；页面为空时提示下一步；错误直接显示在页面里。剩下的英文小标题都改成了中文。
- **严格 CSP**：媒体、AI、计费几个页面残留的内联样式都移进了样式表。
- **手机**：标签可以横向滑动，卡片竖排显示。

## 结果

- check、build、P0–P17 和 `test:docker` 全部通过。P2、P3 在并行回归时偶发失败，单独重跑后通过。
- `tests/p1` 里的 `summary` 选择器收窄为 `#workspace summary`，因为账号菜单也用了 `<summary>`。
- Codex 审查发现 6 个问题，都已修复：
  - 草稿数多算；
  - 非全局管理员看不到最近活动；
  - 命令面板的可访问性和输入法问题；
  - 账号菜单的可访问名称和 Esc 键；
  - 新样式影响了前台；
  - 残留的内联样式。
