## 内容

- **sitemap**：
  - 首页、目录、分类、标签、榜单和对比页排在最前，之后是所有条目，条目带 `lastmod`。
  - 超过 45,000 个 URL 时，`/sitemap.xml` 改为 sitemap index，指向 `/sitemap-<n>.xml`。每个分片只查询自己的那一段，不再一次性生成全部内容。
  - 过滤 XML 1.0 不允许的控制字符。
- **RSS**：`/<locale>/feed.xml`，收录该语言最新的 50 条。
- **替代品页**：`/<locale>/<catalog>/<slug>/alternatives`。
  - 与当前条目共享分类或标签的条目会被列出：共享一个分类计 2 分，共享一个标签计 1 分。先在最多 1000 个候选里打分，再取最高的 24 条。
  - 少于 3 条时页面 noindex。hreflang 只列出页面可以被收录的语言。
- **对比页**：`/<locale>/<catalog>/compare/<a>-vs-<b>`。
  - 按语言保存，有版本号，标识发生冲突时返回 409。只有已发布、且两边条目都可见时才公开。
  - AI 任务类型 `compare` 只起草内容，需要人工审核后发布。详情页会列出包含该条目的对比。
- **模板能力声明**：`TemplateDefinition.supports` 声明模板是否支持替代品页、对比页。不支持的模板（basic、editorial）访问这些路由返回 404，sitemap 也不收录对比页。
- **保留字**：`category`、`tag`、`collection`、`compare` 不能用作条目 slug。分类、标签、榜单、对比这几类路由的优先级高于替代品页。
