## P9 覆盖

- 迁移：提示词版本号从 2 开始，任务类型和指令内容有约束，同一版本号不能重复；对账月份必须是月初，token 数不能为负。
- 提示词：
  - 列表包含内置 v1；
  - 只有站群管理员能新建版本，并发新建得到不同的版本号；参数校验；审计；
  - 站点选择版本：版本不存在时返回 400，只读用户不能修改；
  - Worker 把任务记录的那一版指令放进 `<task>`，系统提示不变；
  - 任务创建后再改选择，不影响该任务；重试按重试时的选择；
  - 版本找不到时任务失败（`prompt_missing`），不调用供应商；
  - 浏览器测试：分别以站群管理员、编辑者、只读用户操作。
- 对账：
  - 系统记录（当月任务 + 用量汇总）与供应商数据的计算，包括差额百分比为空的两种情况、站点隔离；
  - 录入覆盖、未来月份拒绝、审计，以及录入不影响预算；
  - 权限矩阵；
  - CSV 导入成功；任意一行有错时整批不写入，并给出行号（还覆盖了表头错误、空文件、超行数、超大小）。
- 余额：
  - 配置校验，保存后清除旧结果；
  - 手动检查的排队与限频，包括 Worker 正在检查时返回 409；
  - Worker 成功读取余额：Bearer 用的是解密后的 API Key，支持数组路径和数字字符串；
  - 每个错误码，并且出错时余额清空；
  - 每 6 小时自动重新检查，停用的配置跳过；
  - 真实请求函数会拒绝解析到私网地址的主机名（端到端经过 Worker）；
  - 浏览器测试：录入月份、差异标红、CSV 行号错误、保存余额配置、检查后显示余额。

## 开发中修复的问题

- 路由顺序：`aiHttp` 对它不认识的 `/ai/*` 路径一律返回 405，导致对账和余额接口不可达。已把 `aiBillingHttp` 移到 `aiHttp` 之前处理，由对账 agent 发现。
- AI 任务列表补充 `promptVersion` 字段，P7 的断言同步更新。

## 未验证 / 保留
