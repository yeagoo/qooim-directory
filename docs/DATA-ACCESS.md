# 公共数据访问与站点边界

状态：P0 已验证最小公共边界，P1 接入正式 Host 路由、后台和缓存；P2 已接入统一视图、搜索、详情、分类、收藏和 SEO，见 [内容协议](P2-CONTENT.md)；后续模板必须继续复用这些边界。适用页面、模板、公开 API、搜索、sitemap、推荐和公开元信息。

## 唯一数据访问边界

公开页面、模板和公开 API → 带可信站点上下文的公共查询接口 → 内部查询及可见性规则 → 数据库。

公开结果必须满足站点有效、模块启用、资源可公开、本站发布有效和语言已发布，并仅返回公共字段。过滤站点后仍返回采集凭证或内部备注同样违规。

站点上下文来自可信 Host 解析，用户提交的 site_id 不能替代它。后台使用独立管理接口并校验范围。预览通过受保护入口读取草稿；可共享规则构件，但必须分离权限和缓存，不能给公开接口暴露任意 includeDrafts 开关。

### 工程保障

- 数据库客户端和表定义只允许内部数据层导入；公开层只依赖公共接口，后台只依赖管理服务。
- 检查直接及间接依赖，不能通过工具函数绕过；迁移、测试等例外显式列出。
- 模板限制访问环境变量、认证内部模块和服务器配置。
- CI 检查边界，故意加入违规依赖必须失败。
- 跨站负面测试覆盖列表、详情、搜索、关联、计数、API 和 sitemap。
- 模板上线前由维护者审查，AI 生成代码同样适用；静态检查不是恶意代码沙箱。

## Host 与未知域名

生产未知、格式非法或未绑定域名返回无品牌 404，不展示其他站内容、不猜测重定向。认证和管理 API 同样必须经过主机身份解析。

默认 Host-only。需要转发 Host 时显式配置可信代理，代理剥离用户传入转发值并覆盖，源站限制入口；不能仅因为转发值命中站点表就信任它。

域名规范化、重复绑定、别名和主域跳转有明确规则，仅重定向到配置目标。开发预览使用显式配置，不依赖生产兜底。健康检查等基础设施端点单独声明，不作为品牌数据旁路。

## 多语言与 SEO

- UI 漏译回退本站默认语言，开发检查报告漏译。
- 资源内容仅为已发布且必填内容完整的语言建立可索引页面。
- 缺失内容语言返回本站缺失页和现有语言链接；未知或不支持语言路径返回 404。
- 不用目标语言 URL 包装默认语言内容并声称译文已完成。
- canonical 指向本站真实公开地址；hreflang 只包含本站已发布语言版本，并保持互相对应。
- sitemap、OG、导航和语言切换使用同一 URL 与可见性服务，默认不跨品牌联动。

## 缓存与多进程一致性

### 普通配置

数据库保存不可变修订和当前指针。进程按站点与修订缓存，初始默认 5 秒 TTL，在 P0 验证、P1 固定上限。该值是配置检查窗口，不是所有请求或 CDN 的全局完成保证。

TTL 内使用完整快照；到期检查权威版本并加载变化。发布进程主动失效，其他进程在检查窗口内收敛。到期后无法读取版本或快照返回 503，不无限延用过期配置。数据库事务避免读取半份发布。

### 访问门控

域名绑定、停站、停模块、紧急下架和发布状态不能只依赖普通配置 TTL。首版每请求在权威查询中检查，数据库失败返回 503；不得输出绕过门控的长期缓存 HTML 或列表。

首版公共可见性查询不使用跨请求结果缓存。静态资源或内容正文可缓存，但输出前检查当前门控。个人区、认证、后台和预览采用私有或 no-store 策略。

因此首版默认不启用动态 HTML 的 CDN 全页缓存。后续启用必须单独验证失效传播、故障恢复和紧急下架时限；本地版本更新不代表 CDN 已清理。性能影响通过容量测试评估。

### 后续结果缓存

未来缓存键需包含站点、语言、发布修订、影响结果的配置版本与筛选参数。共享资源变化跟踪受影响站点，过期数据不能重新暴露已撤销内容。登录、权限撤销不使用展示缓存。

## 失败验收

验证伪造转发头、跨站 slug/API/计数、匿名草稿预览、过期配置读取失败、热缓存下停站下架、权限撤销、缺失译文 SEO 以及模板间接访问数据库。
