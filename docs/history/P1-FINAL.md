## Review 修复记录

| 问题 | 修复及证据 |
| --- | --- |
| OAuth 自定义用户资料遗漏 sub，首次共享登录失败 | 保留通过 ID token 与 userinfo 一致性检查的 sub；真实浏览器验证共享身份 |
| 本地 HTTP 演示与 Web OIDC 回调约束冲突 | 演示改本地 HTTPS；共享模式创建阶段拒绝 HTTP，不放宽协议校验 |
| 后台域名可换端口注册为公开站 | 按 hostname 禁止冲突，因为 Cookie 不按端口隔离 |
| 认证最后一次执行中断后停在 provisioning | 无活跃 advisory lock 时判定失败，允许重新排队 |
| 维护循环始终检查同一批有效会话 | checked_at 排序轮转，保留批量上限 |
| 公开语言路径误读默认语言 | 按已校验路径语言查询；无译文不回填默认语言内容 |
| 文件导入后表单修改被忽略 | 文件载入字段，继续编辑进入同一候选；错误站点导入拒绝 |
| 发布进程仍持有旧展示缓存 | 事务发布成功后主动失效；两个独立 Next 进程验证收敛 |
| 发布失败事件缺少后台恢复入口 | 显示失败原因、受权重试、审计、幂等消费，不生成另一份修订 |
| 重定向响应头不可变导致未登录后台异常 | 复制响应后统一添加安全头；验证 303、Location 和 no-store |
| CSP 与草稿预览冲突 | 不使用动态 document.write，改授权 HTML 路由；移除内联样式 |
| PostgreSQL 初始化健康误判 | TCP 健康检查避开临时 Unix socket 初始化服务 |
| 演示代理未匹配域名返回空 200 | 显式通用 404；源站仍独立校验 Host |

审查为实现者执行，不是第三方安全审计。SQL 值参数化，动态认证表名只由数据库生成数字 ID 构成；模板边界检查禁止直接/间接访问数据库、环境与认证内部模块。未将静态检查称为安全沙箱。
