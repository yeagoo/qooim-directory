# 主档新版比较与草稿保留 Review

日期：2026-10-20。本轮修复后台“载入并比较主档新版”的数据基线，沿用现有 GET 比较接口、权限和保存/发布双版本检查。未修改依赖、正式迁移、旧站或 Worker。

## 问题与修复

旧实现只查询 publication，始终从线上记录生成比较候选。运营者已经另行保存的草稿，其 slug、分类、排序和本站覆盖值会被退回线上值；未首次发布的草稿也会返回 404。

现在在同一只读、可重复读事务中查询本站同语言的草稿、发布记录和主档版本。存在有效已保存草稿时，以完整草稿为基础，仅更新 resourceVersion 到当前主档版本；草稿为空或发布已消费草稿时，回退到线上发布记录。明确清空的 overrides、categoryId:null 和 rank:0 都保留，不按字段回退到旧线上内容。

只有草稿、尚未发布时也可比较，sourceVersion 为 0，差异的线上原值为 null。既无有效草稿也无发布记录仍返回 404。最新主档缺少完整目标语言时仍拒绝生成候选，不使用其他语言替代。分类和资源版本校验继续复用 material。

差异仍表示当前线上内容与生成候选的比较，不只是主档自身的变更，因此可能包含已保存的本站草稿文案。GET 不保存候选、不推进草稿或发布版本、不产生发布历史，也不改变线上可见性。后台明确提示先保存本页编辑再比较：比较接口不接收尚未保存的 JSON，点击载入仍会采用服务器候选。

只读比较不会赋予编辑器更新的写入版本。若其他人在页面打开后保存了草稿，比较能读取新草稿，但当前编辑器后续保存仍带原 expected 双版本；冲突时保留输入，须重新读取并明确选择后再操作。

## 验证

新增 8 项回归，其中 6 项使用真实测试数据库，2 项使用真实 HTTPS 与 Chromium：已保存草稿所有本站字段保留、首次发布前比较及私有性、空草稿回退与跨站/跨语言隔离、缺失分发或完整译文、只读角色权限、明确清空覆盖与分类，以及浏览器中比较后明确保存发布和外部修改后的 409。校验草稿版本、候选、发布快照及历史，防止仅凭提示文案判定成功。

最初 5 项回归在旧实现全部失败，修复后全部通过；扩展 8 项均通过。完整 P1/P2/P4 共 185 项，发行测试 69 项，共 254 项；生产构建、类型及边界检查通过。未重验 Docker 安装、容量或真实外部 OAuth。
