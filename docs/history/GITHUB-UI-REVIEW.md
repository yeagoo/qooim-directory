# GitHub 来源与候选交互 Review

日期：2026-10-20。本轮为实现者 Review，修改管理页面交互和回归测试，沿用来源、同步任务与人工审核接口。未修改旧站、正式迁移、依赖或 Worker 策略。

## 发现与修复

来源保存、同步排队、应用候选和拒绝候选原先只禁用被点击按钮。现在四类写入共享等待状态，同时冻结来源输入、候选选择、字段复选框及其他动作，并保留控件原有禁用状态。顶部路由导航仍可使用，既有作用域检查继续隔离离开页面后的结果。

POST 成功后的列表或详情读取失败，原先会覆盖成功提示并重新开放旧表单。现在保留具体提交确认，关闭继续写入，只提供“重新读取”和“放弃本页来源编辑并重新载入”。恢复按钮只执行 GET；新建成功后使用返回的来源 ID 恢复，不重发创建请求。恢复成功后清除刷新失败提示。同步 POST 失败时重试沿用同一 operationId；成功后才生成下一次操作标识。

同步、审核、刷新候选和列表分页保留当前来源未保存的输入，同时保留其原 expectedVersion，不因刷新到新版本而升级旧编辑的覆盖权限。明确放弃本页编辑时才采用服务器内容。保存来源成功则清除已提交的编辑快照。

候选选择与字段确认绑定候选 ID、候选版本、来源版本和当前主档版本。读取后上述版本相同且候选仍待审，才恢复选择；任一版本变化或候选不再待审，清空选择并要求重新确认。保存来源或完成审核后也清空候选确认。切换到其他来源或新增来源会打开相应表单，不跨来源保留编辑。

## 验证与边界

新增 11 个浏览器用例：四类写入等待互斥及提交后读取失败恢复；未保存来源与旧编辑版本；候选确认在版本不变、来源变化、候选变化和主档变化时的处理；新建确认后按返回 ID 恢复；同步失败重试标识与未提交输入保留。最初 9 个用例在旧实现中 6 个失败、3 个通过，修复后全部通过。

本轮完整 P1/P4 回归为 111 项，发行测试 69 项，共 180 项；构建、类型与边界检查通过。新增浏览器异常路径采用拦截管理接口的确定性响应，已有 P4 用例仍覆盖真实测试数据库、模拟 GitHub HTTPS 服务、Worker 和审核发布链路。未进行真实 GitHub/Google OAuth 凭据联调或 Docker 安装重验。

源码重新打包、导出并核对工作区/导出目录/归档逐文件摘要及公开文档本地链接。品牌、真实外部联调、4 项依赖许可证材料及 7 项镜像材料核查仍为发行前置项；本轮没有放宽门禁，也不据此宣称正式发行完成。
