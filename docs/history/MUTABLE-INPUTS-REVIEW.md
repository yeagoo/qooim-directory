- 十条快照的精确来源、固定/可变引用标记、原始摘要和大小；拒绝遗漏、重复身份、篡改、链接和未绑定索引。

- 当前观察不能提升成历史构建已验证；修改校验模块而未更新审查绑定也会拒绝。

派生结论按结构比较，JSON 键顺序变化不影响有效材料。校验不是任意 patch 或 shell 的执行器，也不执行下载的代码。逐文件沿用已有证据检查的 2 MiB 上限。

本轮不新增应用依赖或运行服务；原始来源请求记录只读取得，不联系上游。原始快照及索引随源码导出，完整网络请求日志留本地，不公开重定向凭据或私密环境信息。
