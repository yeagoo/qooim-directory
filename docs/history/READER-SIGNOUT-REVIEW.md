# 读者退出交互 Review

日期：2026-10-20。延续 [收藏跨重绘操作 Review](FAVORITE-REDRAW-REVIEW.md)，检查读者页退出等待、重复事件与失败重试。复用原 `/api/auth/sign-out`，不改变本站退出、账号空间或共享登录协议。

## 问题与修复

原退出按钮在请求期间仍可点击，事件处理也没有等待守卫，连续操作会并行发送多个 POST。现在先设置页面内 signingOut 状态并禁用按钮，事件处理再次检查该状态。成功后保持等待直至返回本站首页；失败后恢复按钮及状态，允许用户明确重试，保留个人页未提交输入。

公共 API 错误解析原本只读取业务接口的 error，认证接口返回的 message 被替换为“操作失败”。现在依次采用 error、message 和默认提示，401 仍使用原登录提示；错误文本通过 textContent 显示。认证响应格式已对照本地锁定版本实现核查。这不新增接口，也不把前端等待状态当作服务端或跨标签页互斥。

## 验证

新增 3 项浏览器回归：退出成功和失败两条路径下，等待期间的重复事件只能发出一次 POST；认证 message 正确显示，失败后重试成功。使用实际读者页面与脚本，控制会话查询及退出接口返回，检查禁用状态、请求次数、成功跳转次数、失败不跳转和表单输入保留。三个反例在旧实现全部失败，修复后全部通过。这些受控响应验证前端行为，不作为真实外部平台退出或服务端撤销证据；已有真实会话与退出回归另行保留。

生产构建完成后执行完整 P1/P2/P3/P4 回归 251 项，发行测试 69 项，共 320 项通过；类型与边界检查通过。工作区、导出目录和源码归档逐文件摘要及公开本地链接另行核对。不重验 Docker 安装、容量或真实外部 OAuth。

品牌、真实 OAuth 联调、4 项依赖许可证材料及 7 项镜像核查仍为发行前置项，原有门禁保持阻断；旧站未修改。
