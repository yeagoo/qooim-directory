# P0 最终验收与开发结论

日期：2026-10-18。状态：P0 原定开发范围、实现者 Review 与验证已完成，可以进入 P1。P0 是关键设计验证阶段，完成标准为原验证计划；不是正式导航产品或生产部署验收。

## 交付内容

- 配置快照校验、差异预览、版本冲突、事务发布、幂等操作、回滚及持久化事件消费。
- 独立/共享账号空间、四主域真实 OIDC、规范用户映射、首次并发登录、会话撤销、浏览器预览授权和会话对账。
- 多进程配置收敛、Host 隔离、公共数据投影、模板依赖边界，以及 Next.js 生产构建动态路由。
- 账号空间切换诊断与只读迁移模型；来源核查、认证实施决策和后续投入重估。

本轮没有迁移旧数据、复制旧源码、部署服务或公开仓库。

## 最终 Review 修复

1. **发布连接被终止后的进程错误**：新增统一事务助手，接收已借出连接的错误事件；回滚失败不覆盖原始异常，坏连接销毁而非回池。配置、身份、迁移模型、对账和事件消费共用该助手。真实 `pg_terminate_backend` 测试证明回滚和重试。
2. **账号迁移模型不完整**：补重复收藏、不同站点的相同资源、外部绑定冲突和权限建议。报告始终不可执行，用户映射不等于控制权证明，不自动合并账号或提升角色。
3. **有用户站点切换只返回外键错误**：新增事务化诊断入口，列出受影响成员、会话、收藏及中心引用；空站切换与身份创建使用数据库锁。
4. **邮件/认证来源证据不全**：增加正确空间重置成功、旧密码失效、token 重用拒绝、不可信 Origin 和认证未知 Host 断言。
5. **失败响应已经发出后的异常处理**：认证夹具在已发送响应头时关闭连接，避免再次写入响应头引发二次异常；锁连接失败释放时销毁失效连接。

此前修复见四轮进度报告。本轮为实现者 review 与自动化回归，未开展独立安全审计。

P1/P3 负责动态认证实例管理、生产密钥和迁移、正式后台与认证界面、邮件/外部 OAuth、任务调度、限流及安全审查。P2/P3 负责完整内容入口和模板；P5 负责容量、备份恢复和公开交付。
