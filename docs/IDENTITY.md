# 账号空间与会话设计

状态：首版设计约束；P0 已完成库接入与模型验证，实施结论见 [ADR-001](ADR-001-AUTH.md)。P2 已接入按站收藏和投稿，操作协议见 [P2 内容](P2-CONTENT.md)。本文不是现有 API 文档。

## 身份与业务数据

每站归属一个账号空间。独立模式每站一空间，共享模式多个站共用空间并指定账号中心承载站。同一部署支持混合模式。

| 对象 | 约束 |
| --- | --- |
| 用户 | ID 全局唯一，属于一个空间；全局 ID 不表示全局共享身份 |
| 邮箱身份 | 使用一致规范化规则，在空间内唯一；不同空间同邮箱仍是不同账号 |
| 外部登录绑定 | 绑定空间、提供方及稳定主体标识，不跨空间按邮箱自动关联 |
| 站点用户关系 | 验证用户空间匹配目标站，记录站点状态和必要授权 |
| 收藏与投稿 | 包含 site_id 与用户引用，不仅按用户返回全部站点数据 |
| 站点会话 | 绑定用户、空间、站点、中心会话关联与有效期 |
| 管理授权 | 显式站群或站点范围，单独鉴权 |

邮箱规范化、唯一索引和关联规则在 P0 固定，注册、登录、找回密码和导入一致。实际表结构在原型后固定，使用约束和事务共同防止错误归属。

## 登录基线

共享模式中，A 发起注册登录，跳转 B；B 认证后回到 A，建立 A 的 Host-only 会话。随后 C 的登录入口或受保护页面通过 B 已有会话免重复输入凭据，返回 C 建立独立域内会话。

P0 已锁定并验证 Better Auth 1.7.10。此前查阅的 [OAuth Provider 官方文档](https://better-auth.com/docs/plugins/oauth-provider) 支持该研究方向，版本、OIDC、Host 分流和身份桥接现已通过原型验证；正式产品化边界以 ADR-001 为准。

不同主域不能共享同一域 Cookie，跨站 iframe 还受浏览器策略影响，参考 [Cookie 域规则](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie) 和 [第三方 Cookie](https://developer.mozilla.org/en-US/docs/Web/Privacy/Guides/Third-party_cookies)。首版使用顶层跳转，不在所有公开页自动探测。

每空间固定 issuer 和中心地址，每站固定可信回调，不从任意 Host 拼接。校验授权码、PKCE、state、nonce 等适用项；邮件与密码重置链接同样绑定正确空间。

## 故障与退出

| 情况 | 默认行为 |
| --- | --- |
| B 账号域不可达，A/C 正常 | 新登录报错可重试；已有可验证、未过期会话继续使用 |
| 中心不可达且站点会话过期 | 登录失败，不切换 issuer、不降级为共享密码 |
| 数据库不可用或无法确认权限 | 受保护操作拒绝，不伪装成登录成功 |
| 退出本站 | 撤销本站会话，保留中心会话，不自动探测重新登录 |
| 退出整个空间 | 撤销关联中心与站点会话，其他站后续受保护请求失效 |
| 封禁或权限撤销 | 下一受保护请求检查，不依赖展示配置 TTL |

整个应用或数据库故障是所有站的共同故障，B 域名局部故障另测。已有页面 UI 不承诺即时改变，但后续服务端操作必须拒绝失效凭据。首版通过权威存储检查会话状态，不用离线令牌验证掩盖撤销。

## 已有用户的空间迁移

首版新站可选择空间；有账号、业务用户关联或会话后，禁止通过普通配置切换。首版不提供已有用户自动迁移工具。

后续工具须执行以下流程，P0 只验证模型能表达这些情况：

1. 生成用户、外部身份、业务引用、权限和邮箱冲突清单。
2. 制定身份映射；同邮箱不构成合并证明，需双方账号控制权验证或单独审核，未解决冲突阻止切换。
3. 冻结相关写入，备份，保存源目标映射与迁移批次。
4. 分可恢复步骤更新归属和引用，处理重复收藏与投稿；不因合并扩大管理权限。
5. 切换后撤销旧会话、重新认证，验证后开放写入。
6. 中断凭检查点恢复，恢复前不开放双写；切换后的回滚需处理新增写入，不能只改回空间 ID。

空站切换也要验证无业务引用并撤销配置期间产生的会话。仍承载账号空间的站点不能直接删除或更换中心域名，直到专门迁移流程可用。

完整验证清单见 [P0 验证计划](history/P0-VALIDATION.md)，须使用不同主域的本地 HTTPS 和真实浏览器，不能只用子域测试代替。


P3 的外部提供方、验证邮件、密码重置、可信代理、滑动续期/绝对期限及历史清理规则以 [认证操作](P3-AUTH.md) 为准。真实 GitHub/Google 账号联调待凭据，不以受控 OIDC 测试代替。
