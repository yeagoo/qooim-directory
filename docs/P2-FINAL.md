## Review 与修复

- 主档直接更新不能改各站线上内容：发布存完整快照，候选绑定不可变源版本；更新差异保留本站覆盖。
- 首次分发和主档全局操作与站点编辑隔离；分发检查在读取候选材料之前执行，授权范围由后端判断。
- 发布的快照、历史、幂等操作、草稿消费和审计同事务；唯一 slug 或审计写入失败均不留下部分发布。
- 只通过统一公开视图判断可见性；停站、模块、主档公开、下架、分类及语言状态不依赖展示缓存。
- 新增直接业务 SQL 检查，防止新公开路由绕开数据层；配合原有模板/环境/数据库依赖检查，不宣称沙箱。
- 正在编辑的内容保存后保留选择，避免草稿保存后意外改为新记录；并发版本不匹配拒绝写入。
- 资源表单与 JSON 同步；用户投稿表单使用 elements.namedItem 避免与原生表单属性重名。
- 导入不覆盖本地内部备注；导出不携带备注、凭据或会话；整份导入失败回滚。
- 投稿接受与创建主档/草稿原子提交，不自动上线；重复审核冲突，不重复建资源。限额在数据库锁内执行。
- 缺失译文页返回 404，并列出实际可见的本站其他语言；URL 和 XML 使用已注册 origin，不使用转发头。
- 升级保留 P1 的最小记录；不为缺失 URL 的旧资源编造地址；演示初始化只补自己的旧示例，不改已有正式版本和草稿。

Review 为实现者审查，不是第三方审计。
